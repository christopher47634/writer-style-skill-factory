# Security Policy

This repository is a content project (AI style skills) plus one small
dependency-free validator (`validate.py`). Security reports are still welcome and
taken seriously.

## Reporting a vulnerability

Do **not** open a public issue for a security problem.

Report it privately via GitHub private vulnerability reporting:

1. Go to the **Security** tab of the repository:
   https://github.com/christopher47634/writer-style-skill-factory/security/advisories
2. Click **New draft security advisory** and describe the issue.

Please include:

- the affected file(s) and version (commit hash or tag);
- a description of the issue and its impact;
- reproduction steps, if any.

We acknowledge reports and will coordinate on a fix and disclosure before going
public.

## Supported versions

Only the latest release is supported for security fixes.

| Version | Supported |
| --- | --- |
| v1.0.0 (latest) | ✅ |
| Older releases | ❌ |

Security fixes will be released for the latest version; older releases are not
backported.
