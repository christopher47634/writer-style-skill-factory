# 成稿优先协议（共享）

所有 `style-*` 子 skill 引用本文件，不再各自复制。子 skill 只写本作者专属的输出契约与红线。

## 通用规则

1. 用户给出主题后，默认直接交付完整作品；未被要求时，不输出文风分析、规则说明、评分或自检。
2. 一次成稿只选用 5-8 个最能辨识的特征（结构、叙事距离、句式、具体物、情绪、结尾），不平均堆满全部规则。
3. 交付前对照下面的「可观察交付检查」，不通过就先改再交；这些检查都能从最终文本直接核对，不依赖任何内部评分。
4. 不复用原作人物、完整情节、名句和独特意象。主题不典型时迁移观察方式、句法和结构，不强塞旧题材。
5. 事实与用户原意优先于风格；没有来源时不补造史实、引语、数据、署名。
6. 用户明确指定语言、体裁、长度或格式时服从用户；未指定长度时以各 skill 声明的默认长度为准。
7. 不冒充真实作者、媒体或机构，不把生成文字说成原作。

## 可观察交付检查

- 输出结构与该 skill 的「硬输出契约」逐项一致（章节标题、语言、顺序、是否含中文译文）。
- 回复首行就是标题或契约规定的章节标题，没有「好的」「以下是」等寒暄。
- 正文中不出现「自检」「评分」「候选」「大纲」「技法说明」等元话语。
- 成稿长度落在约定范围内；双语输出时译文逐段对应，不写「大意」。
- 未命中该 skill 的专属禁止项与反模式。

## 双语两段式输出

外语创作类 skill（日、德、俄、英原文 + 中文译文）统一为：先给外语原文，再给逐段完整的中文文学翻译，标题同样「外语原题 → 中文题名」；只含这两部分。

## 引用与版权

- 不整段引用受版权保护的当代文本；样本说明里的引文单段不超过 40 个汉字或 25 个外文单词。
- 当代新闻机构、在世创作者的样本只记录来源与抽象特征，示例一律使用自写的仿写文字。
