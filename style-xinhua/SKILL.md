# 新华社写作风格

## 成稿优先协议

> 通用规则（直接成稿、可观察交付检查、双语两段式、引用与版权）见 [shared/protocol.md](../shared/protocol.md)。本节只列本 skill 的专属约束。

- **硬输出契约**：最终只输出标题与正文（消息稿、通讯或数据稿）。禁止寒暄、提纲、技法说明、评分和自检；禁止自拟电头、记者署名和引语——这三项只在用户材料提供真实信息时照录。
- 默认服从用户指定的长度和稿型；未给长度时生成约 500 字消息稿。
- 不冒充新华社，不生成虚假电头、记者署名、采访、引语、栏目品牌或“新华社消息”。
- 材料不足时省略无法确认的元素或使用明确占位，不为格式完整补造事实。

> 分析基础：18篇新华社/新华网文章，涵盖时政、综合、法治、评论、专题等板块。
> 样本限制：新华社通稿、新华网栏目与评论文章并非同一文体。电头、署名和导语格式只在对应新闻产品中启用。

## 来源记录与引文上限

- 来源：新华社/新华网公开发布的 18 篇文章（时政、综合、法治、评论、专题）；仅作文风特征分析，全文未随仓库分发。逐篇标题与链接记录在作者本地的语料台账中，不入库。
- 权利状态：当代受版权保护的文本 / 在世创作者作品。本文件不整段收录原文，示例一律为自写仿写并标注“（自写仿写）”。
- 引文上限：如确需引用原文短语说明特征，单处不超过 40 个汉字，且不得收录真实标题加首句的组合。
- 通用约束见 [shared/protocol.md](../shared/protocol.md) 的「引用与版权」。

## 一句话定义
导语先行的标准新闻体（正式通稿另有电头，仅在用户提供真实信息时使用）——权威、规范、数据精确，政策导向性极强。

## 一、选题层

| 维度 | 特征 |
|------|------|
| 题材类型 | 时政要闻、政策发布、经济数据、国际关系、法治事件、重大工程 |
| 切入角度 | 从政策/数据/领导人活动/重大事件切入 |
| 问题意识 | 「发生了什么」→「意味着什么」→「下一步怎么做」 |
| 冲突来源 | 发展挑战、外部压力、改革需求（但以正面框架呈现） |
| 关注对象 | 国家层面、政策层面、宏观数据。个体作为案例出现 |
| 选题气质 | 权威、规范、冷静、正面为主 |

选题逻辑：**重大性 > 时效性 > 导向性**。新华社是通讯社，提供信息原材料，不做深度调查。

---

## 二、立场层

| 维度 | 特征 |
|------|------|
| 作者位置 | 官方信息发布者。代表国家通讯社 |
| 对人物态度 | 中性报道，不做评价 |
| 对社会态度 | 正面导向，问题以「解决中」框架呈现 |
| 判断方式 | 通过信息选择和排列体现导向，不做直接判断 |
| 价值底色 | 客观、权威、建设性 |

核心规则：**新华社的立场藏在「报道什么」和「不报道什么」里，藏在引语选择和数据排列里。**

---

## 三、结构层

### 开头（4种范式）

**1. 导语先行（消息稿）**
```
（自写仿写）某市16日发布通知，自下月1日起全面启用新版办事指南，涉及12类高频事项。
```
> 电头、记者署名只在用户明确要求正式通稿格式、且提供了真实发稿地、日期和署名时才按格式补上；示例与默认输出不生成电头。

**2. 政策引用开篇**
```
（自写仿写）根据用户提供的某项政策文件，某区将于下月起试行新的补贴办法……
```

**3. 事实/数据切入**
```
（自写仿写，数字为虚构）某行业协会16日发布数据显示，前三季度某品类出货量同比增长X%（数字以用户材料为准）。
```

**4. 领导人讲话（高规格报道）**
```
（自写仿写）某负责人在座谈会上表示，要把已经确定的工作部署落到具体事项（引语须来自用户提供的材料）。
```

### 中段推进：倒金字塔 + 信息递进

典型推进链：
```
导语（最重要信息）→ 详情 → 背景 → 意义 → 展望
```

深度报道则用：
```
问题提出 → 现状描述 → 数据佐证 → 专家解读 → 政策回应 → 展望
```

### 结尾（4种）

1. 领导人/高层讲话收束
2. 展望未来型
3. 数据+意义总结
4. 署名：仅在用户提供真实署名时照录，否则省略

---

## 四、叙事层

| 维度 | 特征 |
|------|------|
| 叙事视角 | 全知视角/官方视角 |
| 镜头距离 | 远景为主（宏观/全国/全球） |
| 时间处理 | 以现在为主，数据做时间对比 |
| 场景密度 | 极低。几乎不写场景 |
| 人物呈现 | 人物作为信息来源出现，不塑造个体 |
| 信息释放 | 倒金字塔。最重要信息最先给 |
| 叙事速度 | 极快。不铺陈，纯信息推进 |

**通讯社感**：不像纪录片也不像演讲稿，像信息简报。

---

## 五、段落层

典型段落功能分布：
- 信息段：45%（提供事实/数据）
- 引语段：25%（权威来源引述）
- 背景段：15%（政策/历史背景）
- 意义段：15%（分析/展望）

段落较短，每段一个信息点。善用小标题分隔话题。

---

## 六、句子层

| 指标 | 特征 |
|------|------|
| 句子长度 | 长句为主，信息密度高 |
| 停顿方式 | 逗号密集，顿号并列 |
| 判断句 | 「是」「意味着」「标志着」 |
| 排比句 | 高频。「以开放促改革，以开放促发展……」 |
| 口语程度 | 纯书面 |

四字格/对仗：「蹄疾步稳扩大高水平对外开放」「新动能、新优势、新活力」

---

## 七、词语层

### 推荐词库（新华社专用）
```
显示、表明、据介绍、数据显示、同比增长、创历史新高、
标志着、意味着、据了解、记者获悉
```

### 引述动词标准化
```
介绍、表示、说、认为、强调、要求、指出、提出
```

### 数据使用（极度精确）
```
数字原样照抄用户材料的精度与单位，如“同比增长X%”“Y万人次”“占总人口的Z%”（X/Y/Z 为占位，不得自行补小数位）。
```

|------|------|
| 情绪强度 | 2-3/10。极度克制 |
| 情绪外露 | 几乎不外露 |
| 情绪来源 | 来自数据和事实，不来自情感 |
| 情绪曲线 | 平坦。从头到尾冷静 |
| 是否克制 | 是。标准体不允许情绪化 |
| 底色 | 冷静、客观 |

## 九、传播层

| 维度 | 特征 |
|------|------|
| 标题类型 | 主副标题破折号分隔、疑问句式、品牌栏目标识 |
| 开头吸引力 | 靠权威性和数据抓人 |
| 信息钩子 | 政策发布、数据发布 |
| 金句密度 | 低。不追求金句 |
| 转发理由 | 权威信源、第一时间 |
| 平台适配 | 通稿体，全平台分发 |

品牌栏目：「新华视点」「权威数读」「国宝画重点」

## 专属反模式

1. 不出现自拟的“新华社××电”电头、“（记者×××）”署名或“新华社消息”字样。
2. 不补造数字、小数位、同比数据或职务名称；材料没有的数字用占位或省略。
3. 不写“令人振奋”“意义深远”等无来源评价句堆叠；判断须由信息排列体现。
4. 不把评论体、口号式排比用于消息稿。

---

## 写作自查清单

- [ ] 若是正式消息稿且用户提供了发稿地/日期，电头是否按用户提供的信息书写；否则是否已省略？
- [ ] 导语是否包含最重要信息（5W1H）？
- [ ] 数据精度是否忠实于原始来源，而非人为补足小数位？
- [ ] 引语是否来自权威来源？
- [ ] 引述动词是否标准化？
- [ ] 是否使用倒金字塔结构？
- [ ] 段落是否一段一个信息点？
- [ ] 情绪是否克制在3/10以下？
- [ ] 署名是否仅来自用户材料（无则省略）？

---

## 执行协议

1. 先确定消息、通讯、解释性报道、评论或数据稿。只有正式消息稿才考虑电头和标准署名。
2. 5W1H、政策名称、人物职务、日期、地点、数字和引语必须有来源。
3. 不得为了“权威感”补造小数位、同比数据、领导讲话、记者获悉内容或发布机构。
4. 导语优先写最重要且已确认的信息；材料缺失时用占位说明或请求补充，不猜测。
5. 不冒充新华社，不生成虚假电头、记者署名、栏目品牌或“新华社消息”。
6. 评论性判断与新闻事实分开；不把宣传性措辞当作客观事实。

**硬门槛：准确性高于格式完整。没有可靠材料时，宁可省略电头、数字和引语。**
